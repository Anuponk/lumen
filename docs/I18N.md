# Internationalisation (web and installed PWA)

The web site and the installed Android TWA/PWA share the same `index.html` and
`src/main.js` entry point; there is no separate native Android interface here.

## Initial foundation

- Supported locales: French (`fr`) and English (`en`).
- The language selector appears in the game's header and stores the choice in
  `localStorage["lumen.locale"]`. Without a saved choice, the browser language is
  used; unsupported languages fall back to French.
- `src/ui/i18n.js` is a conservative bridge for existing static copy. It only
  translates explicitly listed French strings and known translated equivalents,
  including newly mounted DOM nodes. Unknown content, nicknames and player
  messages are not passed to an external translation service.
- The default French experience remains unchanged for French browsers. Switching
  languages does not reset progress and does not write to cloud player records.
- PWA offline precaching discovers the module through `src/main.js` imports.

## Limitations before calling Lumen fully multilingual

This initial bridge does **not** translate all runtime-generated UI copy,
catalogue/story text, validation errors, notification templates, tutorials, the
manifest installed-app description, or static SEO social-share content. Most
gameplay copy is hard-coded in `src/ui/game-screen.js` and related modules.

Follow-up tasks before declaring FR/EN complete:

1. Extract every player-facing string in HTML and JavaScript into keyed
   FR/EN locale catalogues and replace implicit DOM rewriting with `t(key, params)`
   at render time. Include pluralisation, numbers, dates and time formatting.
2. Translate onboarding, quests, badges, success screens, account/auth,
   accessibility labels, errors, offline/reconnection states and push notifications.
3. Localise website landing/SEO pages and language-specific metadata, manifest
   handling and sharing previews without breaking canonical URLs.
4. Test both languages on desktop, narrow mobile screens, installed PWA,
   offline mode and the Android TWA. Validate persistence, account switching,
   browser language detection and no accidental translation of user data.

Run foundation tests with `node --test tests/i18n.test.mjs`.
