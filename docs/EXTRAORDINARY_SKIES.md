# Ciels extraordinaires — direction créative

Référence créative de #67. Ce document ne publie aucun contenu jouable : il définit le cadre éditorial des futurs packs.

## Principes

Le **Vrai ciel** apporte prestige, astronomie et découverte. Les **Ciels extraordinaires** apportent surprise, collection, humour, poésie et parfois absurdité assumée.

Ils ne doivent jamais donner l’impression d’être du remplissage faute de vraies constellations. Au contraire, ils doivent devenir une raison positive de poursuivre Star Puzzle après le ciel réel.

## Naming

Un Ciel :
- 2 à 5 mots ;
- nom évocateur plutôt qu’une catégorie fonctionnelle ;
- cohérent assez longtemps pour accueillir plusieurs constellations ;
- éviter l’abus de « cosmique / quantique / galactique ».

Une constellation :
- 1 à 4 mots ;
- image mentale immédiate ;
- silhouette capable de justifier le nom ;
- humour dans le concept, pas nécessairement dans chaque intitulé.

## Contrat de silhouette

- 7 à 14 étoiles principales ;
- 1 forme dominante ;
- au maximum 2 appendices importants ;
- lisible à environ 120 px ;
- identifiable en 1 à 2 secondes après révélation ;
- pas plus de 3 branches depuis une même étoile ;
- éviter les croisements gratuits ;
- conserver les espaces négatifs utiles.

Une silhouette est validée si elle reste reconnaissable sans son nom pour au moins 2 personnes sur 3 en test informel, reste lisible sur mobile et n’impose aucune contrainte au moteur de grille.

## Ciel 1 — La Ménagerie des Étoiles
Ton : merveilleux, attachant, légèrement espiègle.

1. **Le Chat Perché** — oreilles + dos + longue queue.
2. **Le Canard** — bec court + poitrine + dos horizontal.
3. **Le Renard aux Trois Lunes** — museau + oreilles + grande queue.
4. **La Baleine Légère** — dos arqué + nageoire + queue.
5. **Le Hérisson Royal** — dos en pointes + museau.
6. **La Chouette Veilleuse** — yeux suggérés + ailes courtes.
7. **Le Cerf des Brumes** — bois simples + tête allongée.
8. **La Tortue Voyageuse** — carapace ronde + tête courte.

## Ciel 2 — Le Grenier des Égarés
Ton : tendre, drôle, quotidien devenu merveilleux.

1. **La Chaussette Solitaire** — tube courbe + pied net.
2. **La Clé Oubliée** — anneau + tige + dents.
3. **La Théière** — corps + bec + anse.
4. **Le Parapluie Retourné** — arche + manche courbé.
5. **Le Grille-pain** — rectangle incliné + fentes suggérées.
6. **La Petite Cuillère** — ovale + manche long.
7. **Le Bouton Perdu** — contour rond + quatre points suggérés.
8. **La Valise Sans Étiquette** — rectangle + poignée.

## Ciel 3 — Les Songes de Minuit
Ton : poétique, étrange, doux, légèrement surréaliste.

1. **La Maison qui Flotte** — toit + base + deux étoiles suspendues.
2. **L’Escalier vers Rien** — marches se terminant dans le vide.
3. **La Lune dans une Tasse** — tasse + croissant.
4. **Le Poisson-Volant** — poisson allongé + ailes.
5. **Le Nuage à Pattes** — arche + quatre points bas.
6. **La Porte entrouverte** — rectangle cassé + diagonale.
7. **Le Cerf-volant endormi** — losange + ficelle.
8. **Le Piano des Ombres** — forme basse + couvercle relevé.

## Ciel 4 — L’Hiver de Verre
Ton : lumineux, calme, cristallin, saisonnier sans être seulement Noël.

1. **Le Cerf de Givre** — bois géométriques.
2. **Le Flocon Roi** — symétrie radiale simplifiée.
3. **La Lanterne** — rectangle resserré + poignée.
4. **Le Traîneau** — base longue + courbe avant.
5. **Le Sapin de Verre** — triangles successifs + tronc.
6. **La Moufle** — paume + pouce lisible.
7. **Le Chalet Allumé** — toit + façade + cheminée.
8. **L’Étoile des Neiges** — étoile irrégulière à six directions.

## Ciel 5 — Le Panthéon de Travers
Ton : personnages célèbres revisités avec respect, humour visuel et silhouettes iconiques.

Ce Ciel privilégie les **figures historiques, mythologiques ou du domaine public**. Une personnalité moderne ou un personnage issu d’une licence commerciale ne doit être utilisé qu’après validation des droits.

1. **Le Petit Empereur** — bicorne + profil compact, évocation napoléonienne.
2. **La Reine du Nil** — coiffe géométrique + profil, évocation de Cléopâtre.
3. **Le Génie Ébouriffé** — chevelure explosive + moustache, évocation scientifique sans portrait réaliste.
4. **L’Homme au Chapeau** — silhouette de peintre + chapeau large, hommage artistique.
5. **Le Barde à la Lyre** — profil + lyre, figure antique.
6. **La Pucelle en Armure** — casque + bannière, figure médiévale.
7. **Le Maître au Compas** — barbe + compas ouvert, figure de savant de la Renaissance.
8. **Le Roi Soleil** — perruque rayonnante + manteau stylisé.

Règle : on reconnaît une **évocation iconique**, pas un portrait réaliste ni une caricature dégradante.

## Ciel 6 — Le Bazar Impossible
Ton : franchement farfelu, absurde, mémorable, presque « pourquoi ça existe ? ».

1. **Le Croissant à Réacteur** — viennoiserie + deux flammes.
2. **La Licorne en Trottinette** — corne + dos + guidon improbable.
3. **Le Poulpe Comptable** — tête ronde + tentacules + calculatrice suggérée.
4. **La Banane Chevalier** — courbe de banane + petit bouclier.
5. **Le Canapé Volant** — assise + dossier + deux ailes.
6. **Le Lama Astronaute** — long cou + casque bulle.
7. **La Cafetière Pirate** — bec + anse + pavillon.
8. **Le T-Rex Pianiste** — grosse tête + petits bras + clavier horizontal.

Ce Ciel doit être utilisé comme terrain d’expérimentation. Le critère principal est : **est-ce que le joueur a envie de montrer cette constellation à quelqu’un ?**

## Rythme d’un Ciel

Pour 8 constellations :
- 2 simples / iconiques ;
- 3 intermédiaires ;
- 2 surprises ;
- 1 pièce maîtresse finale.

La finale doit être plus mémorable visuellement, pas nécessairement plus difficile en gameplay.

## Micro-lore

Optionnel, une phrase de 80 à 140 caractères, jamais nécessaire au jeu.

Exemples :
- La Chaussette Solitaire : « On dit que sa jumelle tourne encore quelque part derrière une étoile. »
- Le Chat Perché : « Il a trouvé le seul rebord assez haut pour observer toutes les nuits à la fois. »
- L’Escalier vers Rien : « Personne ne sait où mène la dernière marche. C’est peut-être pour ça qu’on la monte. »
- Le Poulpe Comptable : « Huit bras, huit colonnes, et pourtant il manque toujours une facture. »
- Le Croissant à Réacteur : « Personne ne sait qui a eu l’idée de le chauffer autant. »

## Mon ciel

Conserver une seule interface :
- sélecteur de Ciel ;
- Ciel verrouillé montré comme une carte mystérieuse ;
- même grille de constellations ;
- identité propre par fond, illustration, microcopy et silhouettes ;
- révélation progressive ;
- silhouette + nom clairement révélés à 100 % ;
- célébration courte à la fin d’un Ciel.

## Séparation avec le gameplay

La silhouette n’impose aucune région, solution ou géométrie de grille.

Pipeline :
1. générer et auditer les puzzles ;
2. affecter les quêtes à une constellation ;
3. la progression allume les étoiles ;
4. la forme artistique peut évoluer sans invalider une grille.

## Fiche obligatoire

Toute constellation extraordinaire contient :
- `id` stable ;
- Ciel ;
- nom affiché ;
- concept ;
- rôle : simple / intermédiaire / surprise / finale ;
- 7–14 points normalisés ;
- connexions ;
- détail distinctif ;
- micro-lore facultatif ;
- test mobile ;
- statut : concept / silhouette validée / contenu prêt ;
- si elle évoque une personne ou licence connue : statut de validation juridique / droits.

## Décisions différées

Le document ne fixe pas : nombre de quêtes, taille commerciale des packs, prix, paiement ou ordre de vente. Ces décisions restent liées à #47/#34 et aux données d’usage.
