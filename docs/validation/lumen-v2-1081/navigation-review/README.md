# Mon ciel et navigation · Révision de conception

La vue initiale montre la progression de l’aventure ainsi que le tracé et l’état
des constellations. Le bouton Badges affiche le détail des compteurs par catégorie
et le total dans la même vue. Les compteurs restent également disponibles dans
le détail d’une constellation.

[Contrôles Edge](browser.json). Les dix constellations sont visibles au-dessus de
la barre aux quatre tailles et les 50 états du storyboard s’ouvrent. Les scénarios couvrent la reprise directe, la
pause et la conservation des marques du prototype, le retour depuis une fiche
avec le filtre conservé, les sélections indépendantes de Mon ciel et des
Classements, le swipe sur une carte et le retour depuis le Défi. Les marques
sont des données de simulation en mémoire.
