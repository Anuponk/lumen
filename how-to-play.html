How to play Lumen

Every Lumen puzzle can be solved by logic. Learn the rules, then work through the first quest with a real puzzle from the game.

Play Lumen

The rules

The N × N board is divided into N colored territories. Place N Guardians using these rules.

  1. Place one Guardian in each row and one in each column.
  2. Place one Guardian in each colored territory.
  3. Keep them apart. Two Guardians can never touch, even diagonally.

Each puzzle has a unique solution. The quest is complete when you place all N Guardians correctly.

The first quest, step by step

Step 1 — the one-cell territory

The purple territory has only one cell. Its Guardian must go in row 3, column 3. You can rule out the rest of row 3 and column 3, plus any cells touching the Guardian, including diagonally.

Step 2 — the only open cell

The orange territory has only one open cell after step 1, in row 5, column 4. Put its Guardian there and rule out the rest of its row, column and neighboring cells.

The solution

Use the same reasoning to find the other Guardians. They go in row 1, column 2, then row 2, column 5, and row 4, column 1.

In the game

  • Tap a cell once to mark it as excluded, twice to place a Guardian and three times to clear it.
  • Drag across empty cells to exclude them in one move.
  • The first quest guides you step by step. You can use hints when you get stuck or solve puzzles unaided to earn badges.

Relight your sky

Each solved puzzle lights up a star in a real constellation. Keep playing to discover all 88 constellations. Learn the constellations.
